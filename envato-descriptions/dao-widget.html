DAO Widget — Governance and Proposals for your crypto token

Enable your token holders to create proposals and vote without gas fees. Based on snapshot.org infrastructure. Embeddable JavaScript widget — works on any website.

Live Demo | Static Demo

Key Features

- Create proposals and vote — gas-free
- MetaMask wallet integration
- Customizable voting periods
- Vote tracking and listing
- Multi-blockchain: ERC20, BEP20, any EVM network
- Light and dark themes
- Configurable token requirements for proposal creation and voting
- ENS domain support
- Simple HTML/JavaScript embed — works on any website

Use Cases

The widget is designed for diverse organizational structures including:

- Community groups and DAOs
- Developer teams
- Worker cooperatives
- Virtual worlds and metaverse projects
- Venture capital firms
- Media companies
- Insurance protocols
- Trust funds

How it works

Embed the widget on your website, configure your token address and voting parameters. Token holders connect their wallets, create proposals, and vote — all without paying gas fees.

Supported Networks

- Ethereum Mainnet
- Binance Smart Chain (BSC)
- Any EVM-compatible blockchain (configurable chainID)
