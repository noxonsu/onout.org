Key Features

- Deploy your own DEX smart contract in 2 clicks
- Set custom commission (0.05% — 20%) and earn from every swap
- Custom branding: logo, colors, domain name
- Manage token lists in the interface
- MetaMask integration for admin authentication
- Uses verified Uniswap source code
- WordPress plugin — install in 1 minute

How it works

Install the plugin, connect MetaMask, deploy your DEX smart contract, customize branding, and start earning commission from every token swap on your platform.

Security
