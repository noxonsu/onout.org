1C ↔ WordPress Sync

Prices and stock auto‑updates without manual work

Overview

Automatic synchronization of prices and stock from 1C into a WordPress (WooCommerce) store. Handles legacy encodings (Windows‑1251), optimized DB and caching to keep the site fast.

Key features
  • 1C export (XML/DBF/TXT) → WooCommerce
  • Encoding auto‑detection and conversion
  • Optimized DB, caching, detailed logs
Case

Standard approach split the DB and slowed the site to 10s. We built an optimized, cache‑friendly implementation with proper encoding handling.
