Turn documents into audio in chat

Overview

Bot that accepts PDF/FB2/TXT, converts to audio and returns to the chat. Handy for quick listening, study and accessibility scenarios.

Key features
  • PDF/FB2/TXT input
  • Audio conversion with progress
  • Delivery right into Telegram
Delivery notes

The bot can be adapted for education, accessibility, internal knowledge bases, or paid content delivery. We define accepted file types, maximum document size, voice settings, queue behavior, and how users receive progress updates.

For longer books, the implementation can split audio into chapters, cache repeated conversions, and store source files only for the required retention window. Admins receive clear error messages for unsupported formats or failed conversions.

Safeguards
  • Input validation for file type, size, and text extraction quality
  • Queue and retry handling for long-running conversion jobs
  • Storage rules for uploaded files and generated audio
