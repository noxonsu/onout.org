Yandex Direct MCP Server

Operate ads with voice or AI

Overview

MCP server that lets you run Yandex Direct campaigns via natural language (Claude/Desktop or any MCP client). Generates ad groups, keywords and negatives, validates in sandbox and launches on approval.

Key features
  • Natural language control of campaigns
  • Auto‑create groups, keywords, negatives
  • Sandbox validation + error handling
Delivery notes

The MCP server is designed for teams that want AI agents to work with Yandex Direct through controlled tools. We define which campaign actions are allowed, what requires approval, and how changes are logged for later review.

The setup can expose campaign reads, keyword preparation, budget checks, and draft ad-group creation while keeping destructive actions behind explicit operator confirmation. This makes the agent useful without giving it uncontrolled ad account access.

Controls
  • Scoped API permissions and environment-based credentials
  • Dry-run responses before campaign mutations
  • Audit logs for generated recommendations and applied changes
