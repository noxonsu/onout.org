Fast discovery
  • Stakeholder interviews, KPIs, short glossary
  • Domain map: sections/entities, user events and UI states
  • Integrations map: data owners, SLAs, responsibilities
Practical build‑out
  • Queued requests, media size limits
  • Avatar generation + automatic moderation
  • Quotas, logs/metrics, load management
Architecture notes
  • FAISS/embeddings vs BM25/SimHash for de‑duplication
  • VAD/streaming, diarization, punctuation restoration
  • Alerting with noise suppression and severity levels
  • Caching, queues, retries for robust processing
Pitfalls
  • False duplicates: cosine thresholds tuning
  • Domain drift — adapt LLM prompts and vocab
  • Anti‑bot/429/5xx — graceful offline with cache
Quality & operations
  • SLI/SLO: p95 latency, error budget, uptime
  • Tests: unit/contract/E2E, load; canary releases
  • Observability: structured logs, traces, metrics
  • CI/CD, migrations, rollbacks, health/readiness
Security & data
  • PII encryption at‑rest/in‑transit, key rotation
  • Roles & access, log masking, audit
  • Retention policies, TTL, regional compliance
