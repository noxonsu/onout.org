Telephony Dashboard

Transcribe, analyze, and search calls

Overview

Web dashboard for Asterisk/virtual PBX analytics. Exports calls via API, runs speech‑to‑text and semantic analysis, stores data on client’s server, and provides role‑based access.

Key features
  • Real‑time metrics and KPIs
  • Speech‑to‑text + semantic analysis
  • Role‑based access and secure storage
