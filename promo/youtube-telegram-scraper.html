YouTube → Telegram Scraper

Lead generation from content creators

Overview

Finds YouTube channels by keywords via official API, filters by subs and content quality, extracts Telegram contacts from descriptions, validates them and exports structured lists.

Key features
  • Keyword search via official API
  • Quality/engagement filters and validation
  • CSV/Excel/JSON export with analytics
Delivery notes

The scraper is configured around a specific editorial workflow: source channels, update frequency, filtering rules, summary format, and where posts should be reviewed before publication. It is not intended for blind reposting at scale.

Production versions can include deduplication, source links, moderation queues, topic tags, and Telegram delivery with clear attribution. This keeps the output useful for subscribers and easier to audit.

Anti-spam controls
  • Human review before reposting or publishing generated summaries
  • Source attribution and duplicate suppression for every item
  • Rate limits and channel-specific filters to avoid noisy digests
